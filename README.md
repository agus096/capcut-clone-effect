CAPRUN - APPLICATION FEATURE INVENTORY
English and Indonesian
Scope: Main video editor and the supporting tools in this project.

======================================================================
1. MAIN VIDEO EDITOR
======================================================================

ENGLISH
CAPRUN is a browser-based, non-linear video editor. Import video, photo,
and audio files; drag them to the timeline; edit clips and preview the
result in the player. Media is processed locally in the browser.

BAHASA INDONESIA
CAPRUN adalah editor video non-linear berbasis browser. Impor video,
foto, dan audio; seret ke timeline; edit klip dan lihat hasilnya di
player. Media diproses secara lokal di browser.

1.1 Projects, media, and workspace

ENGLISH
- Create, open, rename, duplicate, and delete projects from the project
  library. Projects and imported media are saved automatically in
  browser storage; media is copied once and can be reused by projects.
- Import media by file picker or drag-and-drop. Browse project-local
  media and built-in library assets; generated thumbnails and audio
  waveforms are shown.
- Optional video proxy playback helps large or high-resolution source
  files preview smoothly while export continues to use the originals.
- Export/import a small JSON project backup. On import, reselect the
  media files; the editor matches them by filename.
- Undo and redo editing actions. The menu also provides the guide,
  keyboard shortcuts, feature settings, custom fonts, and transition
  and skin-tone plugins.
- Resize or hide the left and right panels, focus the player, adjust the
  timeline height, or use full-screen modes. The guide has searchable
  feature documentation.

BAHASA INDONESIA
- Buat, buka, ganti nama, duplikat, dan hapus proyek dari pustaka
  proyek. Proyek dan media yang diimpor tersimpan otomatis di
  penyimpanan browser; media disalin sekali dan dapat dipakai bersama.
- Impor media lewat pemilih file atau seret-dan-lepas. Jelajahi media
  lokal proyek dan aset bawaan; thumbnail dan waveform audio dibuat
  otomatis.
- Proxy video opsional membantu pemutaran pratinjau file besar atau
  beresolusi tinggi; ekspor tetap menggunakan file asli.
- Ekspor/impor cadangan proyek JSON berukuran kecil. Saat impor, pilih
  ulang file media; editor mencocokkannya berdasarkan nama file.
- Batalkan dan ulangi tindakan edit. Menu juga menyediakan panduan,
  pintasan keyboard, pengaturan fitur, font kustom, plugin transisi,
  dan plugin skin tone.
- Atur ukuran atau sembunyikan panel kiri/kanan, fokuskan player,
  sesuaikan tinggi timeline, atau gunakan mode layar penuh. Panduan
  memiliki dokumentasi fitur yang dapat dicari.

1.2 Timeline, tracks, and clip operations

ENGLISH
- Work with Effect, Text, Overlay, Main, and Audio tracks. Lock, hide,
  mute, reorder, and automatically create tracks as needed.
- Drag clips to move or change tracks; trim either end; add gaps,
  ripple-delete, reorder, join, duplicate, repeat, extend to the
  playhead, replace media, or split one or all tracks.
- Select multiple clips by box selection, Ctrl-click, Shift-click, or
  select all. Move, copy, cut, paste, delete, duplicate, or apply
  compatible properties to the selection.
- Use snapping, main-track magnetic no-gap editing, markers, beat
  markers, rulers, playhead navigation, fit-to-project, and timeline
  zoom. The timeline can follow the playhead during playback.
- Adjust clip volume directly on audio waveforms. Detach a video's
  audio, remove silent sections, fit audio to video duration, or fade
  the first and last clips of a project.
- Toolbar operations include left/right trim at the playhead, crop-fill,
  horizontal/vertical flip, 90-degree rotation, mute, quick fades,
  freeze frame, PNG frame capture, picture-in-picture placement,
  all-track controls, project information, and media-memory cleanup.

BAHASA INDONESIA
- Gunakan track Efek, Teks, Overlay, Utama, dan Audio. Kunci,
  sembunyikan, bisukan, urutkan ulang, dan buat track otomatis saat
  diperlukan.
- Seret klip untuk memindahkan atau mengganti track; trim ujung klip;
  tambahkan jeda, ripple-delete, urutkan ulang, gabungkan, duplikat,
  ulangi, panjangkan sampai playhead, ganti media, atau potong satu
  maupun semua track.
- Pilih banyak klip dengan kotak seleksi, Ctrl-klik, Shift-klik, atau
  pilih semua. Pindahkan, salin, potong, tempel, hapus, duplikat, atau
  terapkan properti yang sesuai ke pilihan.
- Gunakan snap, magnet track utama tanpa celah, marker, marker beat,
  ruler, navigasi playhead, pas-kan seluruh proyek, dan zoom timeline.
  Timeline dapat mengikuti playhead saat pemutaran.
- Atur volume klip langsung pada waveform audio. Pisahkan audio dari
  video, hapus bagian hening, sesuaikan durasi audio dengan video, atau
  beri fade pada klip pertama dan terakhir proyek.
- Operasi toolbar mencakup hapus bagian kiri/kanan di playhead,
  crop-fill, flip horizontal/vertikal, putar 90 derajat, mute, fade
  cepat, freeze frame, simpan frame PNG, posisi picture-in-picture,
  kontrol semua track, info proyek, dan pelepasan memori media.

1.3 Player, canvas, and export

ENGLISH
- Preview playback, pause, loop, frame-by-frame stepping, timecode
  entry, and player full-screen. Set preview resolution and project
  aspect ratio; show composition guides and safe zones.
- Drag, scale, and rotate clips in the player. Set project and clip
  backgrounds, including solid colors, images, and blurred backgrounds.
- Export video as MP4 (H.264/AAC when available, otherwise WebM), GIF,
  audio-only WAV, or a PNG still frame. Choose 360p through 4K,
  10-60 fps, bitrate presets or custom VBR/CBR, and a destination
  folder. Rendering is frame-by-frame.

BAHASA INDONESIA
- Pratinjau, putar, jeda, loop, maju/mundur per frame, masukkan
  timecode, dan layar penuh player. Atur resolusi pratinjau dan rasio
  proyek; tampilkan garis bantu komposisi dan safe zone.
- Geser, ubah ukuran, dan putar klip di player. Atur latar proyek dan
  klip, termasuk warna solid, gambar, dan latar blur.
- Ekspor video sebagai MP4 (H.264/AAC bila tersedia, jika tidak
  WebM), GIF, audio WAV saja, atau satu frame PNG. Pilih resolusi
  360p sampai 4K, 10-60 fps, preset bitrate atau VBR/CBR kustom, dan
  folder tujuan. Render dilakukan frame demi frame.

1.4 Video, image, and visual effects

ENGLISH
- Apply built-in video effects: None, Blur, Mono, Vintage, Invert,
  Neon, Glow, and Night. Search, browse categories, and mark favorites.
- Add built-in transitions: Dissolve, Fade, Zoom, Pop, Slide Left,
  Slide Right, Slide Up, and Blur. Install custom transition plugins
  and apply timed transitions to cuts. Automatic photo slideshow
  timing can standardize photo durations and add transitions.
- Apply color filters: Normal, B&W, Sepia, Vivid, Cool, Warm, Fade,
  and Drama. Use adjustment layers and copy visual settings to other
  clips or selections.
- Clip controls include position, scale, rotation, mirroring, opacity,
  blend modes, borders, crop/aspect presets, masks, chroma key, and
  AI background removal.
- Color controls include brightness, contrast, saturation, hue, blur,
  sepia, invert, RGB curves, vignette, film grain, tint, HSL for eight
  color ranges, four color wheels, temperature/tint grading, LUTs
  (.cube), Canon Picture Style files (.pf2/.pf3), denoise, and image
  quality enhancement.
- Additional visual tools include animated Ken Burns zoom, shake,
  motion stabilization, skin retouch, whitening, smooth/glow, skin-mask
  preview, color matching, and effect/adjustment keyframes.
- Add body effects that follow faces, poses, people, or body regions.
  Face Mosaic and Mosaic are built in; custom JavaScript body effects
  can be uploaded or loaded from the effects folder.
- The BodyFx engine supports face/landmark, pose, segmentation, and
  body-part data; 33 chainable GPU shader presets, masks, motion
  trails, outlines, sprites/assets, and music-beat-aware effects.
- Place effects on a clip or on a separate effect track. Edit, replace,
  remove, or copy/paste effects; custom effects can expose adjustable
  number, color, and text parameters.

BAHASA INDONESIA
- Terapkan efek video bawaan: None, Blur, Mono, Vintage, Invert,
  Neon, Glow, dan Night. Cari, jelajahi kategori, dan tandai favorit.
- Tambahkan transisi bawaan: Dissolve, Fade, Zoom, Pop, Slide Left,
  Slide Right, Slide Up, dan Blur. Pasang plugin transisi kustom dan
  terapkan transisi berdurasi pada potongan klip. Slideshow foto
  otomatis dapat menyeragamkan durasi foto dan menambahkan transisi.
- Terapkan filter warna: Normal, B&W, Sepia, Vivid, Cool, Warm, Fade,
  dan Drama. Gunakan adjustment layer dan salin pengaturan visual ke
  klip atau pilihan lain.
- Kontrol klip mencakup posisi, skala, rotasi, mirror, opacity, mode
  blend, bingkai, crop/preset rasio, mask, chroma key, dan penghapusan
  latar AI.
- Kontrol warna mencakup brightness, contrast, saturation, hue, blur,
  sepia, invert, kurva RGB, vignette, film grain, tint, HSL untuk
  delapan rentang warna, empat color wheel, grading temperature/tint,
  LUT (.cube), file Canon Picture Style (.pf2/.pf3), denoise, dan
  peningkatan kualitas gambar.
- Alat visual tambahan mencakup zoom animasi Ken Burns, shake,
  stabilisasi gerak, retouch kulit, whitening, smooth/glow, pratinjau
  mask kulit, penyamaan warna, dan keyframe efek/adjustment.
- Tambahkan efek tubuh yang mengikuti wajah, pose, orang, atau bagian
  tubuh. Face Mosaic dan Mosaic tersedia sebagai efek bawaan; efek
  tubuh JavaScript kustom dapat diunggah atau dimuat dari folder efek.
- Engine BodyFx mendukung data wajah/landmark, pose, segmentasi, dan
  bagian tubuh; 33 preset shader GPU yang dapat dirantai, mask, jejak
  gerak, outline, sprite/aset, dan efek yang mengikuti beat musik.
- Tempatkan efek pada klip atau track efek tersendiri. Edit, ganti,
  hapus, salin/tempel efek; efek kustom dapat menyediakan parameter
  angka, warna, dan teks yang bisa diatur.

1.5 Audio

ENGLISH
- Import music and sound effects, record a microphone voice-over, and
  edit Audio-track clips.
- Adjust volume (including waveform volume lines), fades, 3-band
  equalizer, sound effects (Echo, Reverb, Telephone, Megaphone, Robot,
  Radio, Underwater, and Bass boost), noise reduction, voice
  enhancement, and 17 voice-changer profiles. Reverse playback and
  speed changes are available for clips.
- Remove quiet sections, mark music beats, split on markers, and sync
  an audio clip's duration to the video.

BAHASA INDONESIA
- Impor musik dan efek suara, rekam voice-over dari mikrofon, dan edit
  klip di track Audio.
- Atur volume (termasuk garis volume waveform), fade, equalizer 3 pita,

  Underwater, dan Bass boost), pengurangan noise, peningkatan suara,
  dan 17 profil pengubah suara. Pemutaran terbalik dan perubahan
  kecepatan tersedia untuk klip.
- Hapus bagian hening, tandai beat musik, potong di marker, dan
  sesuaikan durasi klip audio dengan video.

1.6 Text, captions, stickers, and motion graphics

ENGLISH
- Add text clips with editable content, font, color, outline, shadow,
  background, and preset styles such as Title, Subtitle, Neon,
  Handwriting, Impact, Glow, Retro, Caption Box, and Typewriter.

  Pop Title, Lower Third, Kinetic Words, Countdown, and History Title.
  Custom JSX/TSX templates can also be loaded.
- Import SRT subtitles or export timeline text clips to SRT.
- Generate captions locally with Whisper AI or with browser Web Speech.
  Translate captions, make bilingual subtitles, and create AI dubbing
  audio aligned to caption timing.
- Create a video from storyboard JSON: generate narration, fetch images
  from Wikimedia Commons or use supplied media/URLs, and assemble
  Ken Burns photos, transitions, captions, year cards, and titles.
- Create AI motion-graphic videos: configure an OpenAI-compatible API,
  select script and animation-code models, plan scenes, generate
  narration and Remotion animations, inspect previews, repair errors,
  and render the result with captions and transitions.
- Import motion-graphic HTML with its assets, preview it, choose frame
  rate and render scale, then render the animation and audio to the
  timeline.

BAHASA INDONESIA
- Tambahkan klip teks dengan isi, font, warna, outline, bayangan, dan
  latar yang dapat diedit; tersedia gaya seperti Title, Subtitle,
  Neon, Handwriting, Impact, Glow, Retro, Caption Box, dan Typewriter.
- Unggah font TTF/OTF/WOFF/WOFF2 kustom. Tambahkan stiker emoji dan

  Pop Title, Lower Third, Kinetic Words, Countdown, dan History Title.
  Template JSX/TSX kustom juga dapat dimuat.
- Impor subtitle SRT atau ekspor klip teks timeline menjadi SRT.
- Buat caption secara lokal dengan Whisper AI atau Web Speech browser.
  Terjemahkan caption, buat subtitle dua bahasa, dan buat audio dubbing
  AI yang mengikuti waktu caption.
- Buat video dari JSON storyboard: buat narasi, ambil gambar dari
  Wikimedia Commons atau gunakan media/URL yang disediakan, lalu susun

- Buat video motion graphic dengan AI: atur API kompatibel OpenAI,
  pilih model naskah dan kode animasi, rancang adegan, buat narasi dan
  animasi Remotion, periksa pratinjau, perbaiki error, lalu render
  dengan caption dan transisi.
- Impor HTML motion graphic beserta asetnya, pratinjau, pilih frame
  rate dan skala render, lalu render animasi dan audionya ke timeline.

4. SUPPORTING CREATION TOOLS
======================================================================

4.1 Footage Search

ENGLISH
Search stock videos, photos, vectors, SVG, PNG, and PSD assets through
Vecteezy; browse videos, categories, collections, and scenes through
Coverr; or search Pixabay images and videos. Filters include type,
relevance/newest/popular/trending order, duration, AI-content status,
license, family-friendly and safe-search options, category, language,
orientation, minimum dimensions, color, and editor's choice. Results
can be previewed, paged, and opened for a download link. API settings,
quota checks, and provider credentials are provided.

BAHASA INDONESIA
Cari aset stok video, foto, vektor, SVG, PNG, dan PSD melalui Vecteezy;
jelajahi video, kategori, koleksi, dan adegan melalui Coverr; atau cari
gambar dan video Pixabay. Filter mencakup tipe, urutan relevan/terbaru/
populer/trending, durasi, status konten AI, lisensi, opsi ramah
keluarga dan safe search, kategori, bahasa, orientasi, ukuran minimum,
warna, dan pilihan editor. Hasil dapat dipratinjau, dimuat per halaman,
dan dibuka untuk mendapatkan tautan unduhan. Tersedia pengaturan API,
cek kuota, dan kredensial provider.

4.2 Image Generator

ENGLISH
Connect to an image-generation API bridge over MQTT/WebSocket. Set a
prompt, optional negative prompt, style, image dimensions, and number
of images; view generated results, open a lightbox, download, retry,
or clear the gallery. Configure token, request/response topics,
brokers, payload template, and timeout; fetch bridge help and available
styles. Connection and request logs are shown.

BAHASA INDONESIA
Hubungkan ke bridge API pembuat gambar melalui MQTT/WebSocket. Atur
prompt, negative prompt opsional, gaya, dimensi gambar, dan jumlah
gambar; lihat hasil, buka lightbox, unduh, coba ulang, atau bersihkan
galeri. Atur token, topic request/response, broker, template payload,
dan timeout; ambil bantuan bridge dan daftar gaya. Status koneksi dan
log permintaan ditampilkan.

ENGLISH

voice, model, style, rate, and volume.

BAHASA INDONESIA
